# V28 批次 D：真人教学研究实验设计方案

状态：设计稿（待招募执行）。前置依赖：无硬性技术依赖（游戏已具备三组对照与三阶段分指标），但建议在批次 B（真实模型）解除后再启动 LLM 组，避免混淆变量。

## 1. 研究问题

在真实初学者使用场景下，三种提示模式对学习效果的影响是否存在可测差异：

- **G0（none）**：无 LLM、无静态提示（v26 原行为）
- **G1（static）**：静态分级提示 L1~L3（零 LLM 依赖）
- **G2（llm）**：LLM 分级提示 + L4 答后讲解（批次 C 完整闭环）

核心假设 H1：G2 的延迟复习正确率 > G1 > G0。次要假设 H2：G2 的重试成功率（first:miss→retry:ok）高于 G0。探索性问题：错因诊断类别分布是否与知识点分布一致（诊断有效性线索）。

## 2. 被试与分组

| 项 | 要求 |
|---|---|
| 目标人群 | NCE 教材进度相当的真实初学者（小学高年级～初中），母语中文 |
| 样本量 | 每组 ≥ 10 人（总 ≥ 30）；功效分析按检测中等效应 d=0.8、α=0.05、power=0.8 反推最低 26 人，取整 30 |
| 排除标准 | 已系统学过目标语法点者；无法完成两次会话者 |
| 分组方式 | 按 pretest 成绩分层随机化（低/中/高三层内随机分配到 G0/G1/G2），避免能力不均衡 |
| 伦理 | 未成年被试须取得监护人知情同意；数据本地匿名化存储（sid 随机、无姓名）；被试可随时退出且无需理由；实验后向对照组补发完整讲解材料（不剥夺教育机会） |

## 3. 流程（每人两次会话，间隔 ≥ 48 小时）

**会话 1（学习，约 25 分钟）**
1. pretest：10 题（题库外平行卷或同构题），不计入游戏
2. 按组别 URL 参数开局（`?exp=none|static|llm` + `?seed=` 固定题目序列），游玩第 1~2 章，目标作答 25~35 题
3. 错题自然进入错题本（三阶段分指标自动记录：first / retry / review）
4. 会话结束导出 `nce_player_log` 与 savelogs 数据

**会话 2（延迟复习，约 10 分钟）**
1. 仅使用错题本「开始复习」模式，测 delayed-review 正确率
2. posttest：10 题平行卷
3. 主观问卷（5 级李克特）：提示是否有帮助、讲解是否易懂、是否愿意继续使用

## 4. 指标表（全部来自已埋点数据，无需新增开发）

| 指标 | 定义 | 数据来源 | 备注 |
|---|---|---|---|
| 首答正确率 | first:ok / first 总数 | player log phase=first | 三组可比（作答概率与组别解耦已验证） |
| 重试成功率 | retry:ok / (first:miss 且有 retry) | phase=retry | 仅 static/llm 组有 retry 阶段 |
| 提示使用率 | 每题 hint 调用数、cacheHitRate、localFallbackRate | hintStats | llm 组专项 |
| 结算讲解阅读 | L4 展示后停留时长 | L4 展示/清除事件时差 | 探索性 |
| **延迟复习正确率** | review:ok / review 总数（会话 2） | phase=review | **主要终点指标** |
| posttest 提升 | posttest − pretest | 平行卷 | 外部效度校验 |
| 错因分布 | 各诊断类别计数（basis 命中） | 错题本诊断 | 与知识点分布交叉分析 |
| 主观帮助度 | 问卷均分 | 问卷 | 需人工录入 |

## 5. 数据记录与留存

- 游戏侧：server savelogs 已接受 `tag=v4` + `exp` + `hintStats` + 三阶段事件，`log-<sid>.json` 自动落盘 `server/savelogs/`
- 实验侧：每名被试建立目录 `experiment/<date>-cohort1/<sid>/`，存放 savelogs 副本、pretest/posttest 答卷、问卷；附 `manifest.json`（被试编号、组别、分层、会话时间戳）
- 汇总：`experiment/analysis.md` 按第 4 节指标表出三组对照表 + 简单显著性检验（Mann-Whitney U，样本量小不做参数检验）
- 隐私：sid 与真人对应表仅实验者持有，不入库

## 6. 完成标准（批次 D 单独声明，不与功能完成混同）

1. 三组各 ≥ 10 名真实被试完成两次会话，数据完整可分析
2. 主要终点（延迟复习正确率）三组对照表 + 检验结果出具
3. 结论措辞区分「统计显著」「方向性差异」「样本不足无法判定」三种情况
4. 无论结果如何，报告如实呈现——**教学有效性与功能完成是两个独立结论**
